# Model Export

## GLB and glTF

- [ ] Add an Export GLB button.
- [ ] Export the currently displayed model.
- [ ] Export the currently forced LOD.
- [ ] Include referenced textures.
- [ ] Include animations where supported.
- [ ] Include material parameters.
- [ ] Preserve model hierarchy when practical.
- [ ] Preserve mesh and animation names.
- [ ] Add glTF export when external textures are useful.
- [ ] Package glTF and textures into one ZIP.

## Options

- [ ] Add a current-LOD export option.
- [ ] Add an all-LODs export option.
- [ ] Add an animations-on option.
- [ ] Add an animations-off option.
- [ ] Add a current-pose export option.
- [ ] Add a default-pose export option.
- [ ] Add a bake-current-transform option.
- [ ] Add a preserve-local-transform option.

## Warnings

- [ ] Warn about runtime-only shader effects.
- [ ] Warn about procedural textures not baked.
- [ ] Warn about unsupported custom materials.
- [ ] Warn about unsupported audio.
- [ ] Warn about non-exportable event behavior.
- [ ] Warn about missing texture data.
