# Plugin Introspection

## Manifest Contract

- [ ] Define a model lab inspection manifest.
- [ ] Reuse the normal plugin manifest where possible.
- [ ] Give every supported input a stable ID.
- [ ] Give every supported input a display label.
- [ ] Give every supported input a data type.
- [ ] Give every supported input a default value.
- [ ] Give every supported input valid bounds where useful.
- [ ] Give every supported input allowed values where useful.
- [ ] Mark each input as required or optional.
- [ ] Mark inputs that require a model rebuild.
- [ ] Mark inputs that only update runtime state.

## Capability Discovery

- [ ] Read supported LOD levels.
- [ ] Read supported animations.
- [ ] Read supported sounds.
- [ ] Read supported events.
- [ ] Read supported custom parameters.
- [ ] Read supported weather states.
- [ ] Read supported seasons.
- [ ] Read supported day and night behavior.
- [ ] Read supported world-time behavior.
- [ ] Read supported interaction handlers.
- [ ] Read supported export modes.
- [ ] Read supported debug visualization modes.

## Dependencies

- [ ] List required plugin dependencies.
- [ ] List optional plugin dependencies.
- [ ] List supported companion plugins.
- [ ] Show installed dependency versions.
- [ ] Show required dependency ranges.
- [ ] Warn about missing required dependencies.
- [ ] Warn about incompatible dependency versions.
- [ ] Show optional features disabled by missing plugins.
- [ ] Export dependency data in reports.
