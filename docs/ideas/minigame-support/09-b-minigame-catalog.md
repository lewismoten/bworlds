# Minigame Catalog

A large catalog of minigames that can build skills, resources,
achievements, reputation, influence, or world state.

## Suggested Reward Types

- Skill points
- Character experience
- Inventory resources
- Currency
- Achievements
- Reputation
- Settlement influence
- World unlocks
- Cosmetic rewards
- Knowledge or map data
