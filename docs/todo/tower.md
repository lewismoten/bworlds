A tower POI is more of a puzzle where instead of monsters, you are trying to solve a puzzle to reach the next level. These are puzzles like a maze with only one solution where you need to move a box to get past the first level.

- [x] Push an obstruction out of the way
- [x] Find a key to unlock a door
- [x] Jump over an obstacle

Continue adding more types of challenges that get difficult or introduce over time to allow the player to move up to higher levels. In some cases, the player may need to learn a skill or acquire an item, or expendable items to proceed.
