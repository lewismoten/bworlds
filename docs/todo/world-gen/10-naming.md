# World Feature Naming

## Naming Service

- [ ] Create one shared world naming service.
- [ ] Keep names deterministic from feature IDs and seed.
- [ ] Keep names stable after unrelated world changes.
- [ ] Avoid duplicate nearby names.
- [ ] Track used names by category and region.
- [ ] Support regional language and naming styles.
- [ ] Support alternate and historical names.
