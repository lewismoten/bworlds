# Regions and Administrative Borders

## Regions

- [ ] Create a region boundary plugin.
- [ ] Partition settled land into regions.
- [ ] Prefer major rivers as natural borders.
- [ ] Prefer mountain ridges as natural borders.
- [ ] Prefer coastlines as natural borders.
- [ ] Avoid fragmented borders without a reason.

## Counties

- [ ] Create a county boundary plugin.
- [ ] Partition each region into counties.
- [ ] Use towns and travel access as county anchors.
- [ ] Use rivers and ridges as county borders where useful.
- [ ] Keep counties contiguous where practical.

## Magisterial Districts

- [ ] Create a magisterial district plugin.
- [ ] Partition counties into smaller districts.
- [ ] Use population distribution to influence districts.
- [ ] Use roads and settlements to improve accessibility.
- [ ] Keep district boundaries stable from the seed.

## Map Data

- [ ] Expose all border levels to map plugins.
- [ ] Store parent region links on every border object.
- [ ] Support future political ownership separately.
