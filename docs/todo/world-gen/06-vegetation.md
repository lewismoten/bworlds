# Vegetation and Ground Cover

## Forest Floors

- [ ] Make forest ground a floor surface, not a tree tile.
- [ ] Use soil as the base forest floor layer.
- [ ] Add leaf litter as a forest floor splat layer.
- [ ] Add moss where humidity and shade allow it.
- [ ] Add grass where canopy density is low.
- [ ] Add exposed rock where slope requires it.
- [ ] Blend forest floor into nearby open terrain.

## Vegetation Groups

- [ ] Create a vegetation placement plugin.
- [ ] Place vegetation groups instead of isolated noise.
- [ ] Select vegetation families from biome and climate.
- [ ] Favor tropical plants near the equator.
- [ ] Favor temperate forests at mid-latitudes.
- [ ] Favor boreal forests at higher latitudes.
- [ ] Store common plants, animals, fruit, and sizes.

## Constraints

- [ ] Never place normal vegetation on water.
- [ ] Avoid vegetation on very steep slopes.
- [ ] Reduce vegetation on exposed rock and deserts.
- [ ] Reduce vegetation inside settlement clearings.
- [ ] Remove vegetation from roads and rails.
- [ ] Remove vegetation from bridges and docks.
- [ ] Push vegetation farther from wide roads.

## Rendering

- [ ] Render ground cover through terrain splats.
- [ ] Render trees and bushes above terrain chunks.
- [ ] Use instancing for repeated vegetation models.
- [ ] Cull vegetation by distance and visibility.
- [ ] Use vegetation LOD independent from terrain LOD.
