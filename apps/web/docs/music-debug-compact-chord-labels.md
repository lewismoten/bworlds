## Music Debug Compact Chord Labels

When the timeline chord lane is too narrow for the full `Chord N quality` text,
the compact label now keeps an explicit chord prefix instead of showing only the
degree and quality.

Examples:

- `Chord 5 minor` when there is room
- `Ch5 min` when the lane needs the compact form

That avoids the prior `1 min`/`5 min` labels reading like elapsed time.
